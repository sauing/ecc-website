# Join ECC POC

`/join` is an isolated, in-memory registration demonstration. JOIN ECC links point here; Membership remains the programme catalogue.

- Disabled Google button honestly indicates future OAuth integration. Try demo login uses a sample identity, not authentication.
- Editable sample name, address and WhatsApp. No storage, network submission or credentials.
- Seven membership types, junior player name and guardian acknowledgement.
- Demo acknowledgement is not legal policy acceptance.
- Success, cancellation and failure payment simulations. No prices, bank details or payment provider calls.
- Success shows only demo active status and a secretary email preview; sender address is unconfirmed. Nothing is emailed.
- Restart clears state; refresh loses the demo. Member login/dashboard remains unimplemented, deliberately outside this change.

Before launch: verified OAuth, server-side application storage/validation, approved programme prices/eligibility, guardian requirements, real policy texts, verified payment webhooks, secretary email sending and member dashboard.
